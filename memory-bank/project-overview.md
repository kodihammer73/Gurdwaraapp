# Gurdwara Mobile App - Project Overview

## Project Description
A modern, minimalist mobile application for Gurdwara Sahib Melaka that mirrors the website experience. Built using Flutter with a clean, trendy interface appealing to the young generation. Features event management, community announcements, gallery, and spiritual content—all presented in a simple, uncluttered manner.

**Connected to**: https://www.gurdwarasahibmelaka.com

## Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **Design**: Material Design 3 with custom branding
- **State Management**: Provider + Riverpod
- **API Communication**: Dio (connects to gurdwara-v3 backend)
- **Local Storage**: Hive + SharedPreferences
- **Navigation**: GoRouter
- **Android**: Compiled locally on Windows PC to APK
- **iOS**: Built via GitHub Actions for IPA distribution
- **Version Control**: GitHub
- **Target Platforms**: Android (API 21+), iOS (11.0+)

## Key Goals
- Create a modern, trendy mobile app for young Sikh community members
- Keep interface simple, clean, and uncluttered
- Sync seamlessly with existing Gurdwara Sahib Melaka website
- Support both Android and iOS platforms
- Provide smooth, fast performance with minimal data usage
- Enable push notifications for important announcements
- Maintain brand consistency with website design (Saffron/Navy/Gold colors)
